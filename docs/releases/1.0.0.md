Elarydil KVM 1.0 keeps your monitor's input in step with your USB KVM switch on macOS, Windows and Linux. When your keyboard and mouse move to another computer, the monitor follows over DDC/CI, through the video cable you already have.

**Highlights**
- **Setup wizard in four steps.** Press your KVM switch away and back; Elarydil KVM shows every device as it disconnects and reconnects, preselects the fastest ones, and creates a profile with a rule for each direction. Switching is paused while the wizard is open.
- **Rules you can read.** Each rule says which devices it watches and which input it selects. Trigger on all, any or at least N devices, tune debounce, re-arm and cooldown, try a rule with a 15-second **Test**, or run it as a dry run.
- **Your inputs, by name.** Standard DisplayPort and HDMI inputs are ready immediately, the current input is read live, and inputs can be renamed, hidden or added with custom values.
- **Runs quietly in the menu bar or tray.** The background agent starts and stops with the app; turn on *Keep agent running when the app quits* for an always-on setup.
- **Clear errors.** If the agent cannot start, a window explains why and the details are saved to a log.
- **Complete command line.** Everything in the app is available from `elarydil-kvm`, including headless operation without the desktop app.
- **Private by design.** No account, no network listener, no telemetry, no keyboard hooks.

**Downloads**
- macOS 13 or later on Apple Silicon: `Elarydil-KVM-1.0.0-macos-arm64.dmg`
- Windows 11 x64: `Elarydil-KVM-1.0.0-windows-x64-setup.exe`
- Linux x86_64: `Elarydil-KVM-1.0.0-linux-amd64.deb` (Debian, Ubuntu) or `Elarydil-KVM-1.0.0-linux-x86_64.rpm` (Fedora)
- Command line only: `elarydil-kvm-cli-*.zip`

Verify downloads with `SHA256SUMS.txt`.

**macOS**: copy the app from the DMG to Applications and follow MACOS-FIRST-LAUNCH.md for the first launch. **Linux**: monitor control needs access to `/dev/i2c-*`; the README's troubleshooting guide shows how to grant it.
